Webhook
Trigger

Expone una URL HTTP única. Dispara el workflow al recibir una solicitud GET, POST, PUT o DELETE. Es el trigger más universal para integraciones externas, formularios y webhooks de terceros.

HTTPPOST/GETEntradaExterno
🕐
Schedule Trigger
Trigger

Ejecuta el workflow en intervalos definidos: cada X minutos, horas, días o con expresiones CRON personalizadas. Ideal para tareas programadas, reportes automáticos y sincronizaciones periódicas.

CRONPeriódicoTimerAutomatización
▶️
Manual Trigger
Trigger

Permite iniciar el workflow manualmente con un clic desde la UI de n8n. No requiere evento externo. Perfecto para pruebas, flujos on-demand y workflows ejecutados por humanos.

ManualPruebasOn-demand
📧
Email Trigger (IMAP)
Trigger

Monitorea una bandeja de correo vía IMAP y dispara el workflow cuando llegan nuevos emails. Soporta filtros por carpeta, remitente y asunto. Útil para automatizar respuestas o procesamiento de correos.

EmailIMAPInbox
📡
RSS Feed Trigger
Trigger

Monitorea feeds RSS/Atom y dispara el workflow cuando aparecen nuevos artículos. Permite hacer seguimiento de noticias, blogs y publicaciones automáticamente sin APIs propietarias.

RSSFeedNoticias
📋
n8n Form Trigger
Trigger

Genera un formulario web con campos personalizados hospedado directamente en n8n. Cuando alguien lo envía, dispara el workflow con los datos del formulario. Sin necesidad de servicios externos.

FormularioUIInput
🔀
IF
Flow & Lógica

Bifurca el flujo en dos ramas (TRUE / FALSE) basado en condiciones definidas sobre los datos de entrada. Compara strings, números, booleanos, fechas y más. El nodo condicional fundamental de n8n.

CondicionalBifurcaciónLógica
🔃
Switch
Flow & Lógica

Enruta items a múltiples salidas (ramas) según reglas o valores. Similar al IF pero con N salidas posibles. Perfecto para enrutar por tipo de evento, estado o categoría de dato.

RouterMulti-rutaSwitch-case
🔗
Merge
Flow & Lógica

Combina datos de múltiples ramas en una sola salida. Modos: Append (concatenar), Merge by Index, Merge by Key, Multiplex, o esperar ambas ramas (Wait). Esencial para reunir flujos paralelos.

CombinarJoinParaleloWait
🔁
Loop Over Items
Flow & Lógica

Itera sobre items en lotes (batches) de tamaño configurable. Procesa N items por ciclo y vuelve a sí mismo hasta agotar la lista. Útil para respetar rate limits de APIs o procesar grandes volúmenes.

LoopBatchIteraciónRate limit
⏸️
Wait
Flow & Lógica

Pausa la ejecución del workflow por un tiempo definido, hasta una fecha/hora específica, o hasta recibir un webhook de reanudación. Permite flujos asincrónicos con aprobaciones humanas o delays.

PausaDelayAprobaciónAsync
🚨
Error Trigger
Flow & Lógica

Se activa cuando otro workflow falla. Recibe los datos del error (mensaje, nodo origen, stack trace). Permite crear workflows de manejo de errores centralizados con notificaciones o reintentos.

ErrorTry/CatchAlertas
🛑
Stop and Error
Flow & Lógica

Detiene la ejecución del workflow y lanza un error personalizado con mensaje configurable. Ideal para validaciones: si una condición crítica no se cumple, termina el flujo con un mensaje claro.

ErrorValidaciónStop
🌐
HTTP Request
Core

Realiza peticiones HTTP a cualquier API o URL. Soporta todos los métodos (GET, POST, PUT, PATCH, DELETE), headers personalizados, autenticación (Basic, Bearer, OAuth, API Key), body JSON/form y paginación.

APIRESTHTTPUniversal
💻
Code
Core

Ejecuta código JavaScript o Python directamente en el workflow. Accede y transforma los items de entrada con lógica personalizada. El nodo más flexible para transformaciones complejas o lógica de negocio.

JavaScriptPythonCustomLógica
⚙️
Execute Workflow
Core

Llama a otro workflow de n8n y opcionalmente espera su respuesta. Permite modularizar lógica en sub-workflows reutilizables. Soporta pasar datos de entrada y recibir datos de salida del workflow hijo.

Sub-workflowModularReutilizable
✏️
Set
Core

Agrega, modifica o elimina campos en los items. Permite crear nuevas propiedades con valores fijos, expresiones dinámicas o datos de otros campos. También puede limpiar todos los campos existentes.

VariablesMappingTransformar
🗂️
Edit Fields (Set v2)
Core

Versión mejorada del nodo Set. Permite mapear campos de forma visual con drag & drop, renombrar claves, asignar valores con expresiones y controlar qué campos se incluyen en la salida.

MapeoRenombrarTransformar
↩️
Respond to Webhook
Core

Envía una respuesta HTTP personalizada al cliente que disparó el Webhook Trigger. Configura código de estado, headers y body de respuesta. Esencial para workflows que funcionan como APIs.

ResponseHTTPAPI
🔍
Filter
Data

Filtra items que cumplen condiciones definidas. Los que pasan la condición continúan; los que no, se descartan. Soporta múltiples condiciones con AND/OR, comparaciones de strings, números y fechas.

FiltrarCondiciónWHERE
📦
Aggregate
Data

Convierte múltiples items en uno solo. Puede agrupar todos los valores de un campo en un array, combinar items o aplicar funciones de agregación (suma, media, min, max, conteo). Inverso del Split Out.

AgruparReducirArrayGROUP BY
📤
Split Out
Data

Expande un campo array: convierte cada elemento del array en un item individual separado. El inverso del Aggregate. Ideal para procesar listas elemento por elemento en el resto del workflow.

ExpandirUnnestArray
🔢
Sort
Data

Ordena los items por uno o más campos en dirección ascendente o descendente. Soporta ordenamiento por strings (alfabético), números y fechas. También permite orden aleatorio (shuffle).

OrdenarASCDESCORDER BY
🧹
Remove Duplicates
Data

Elimina items duplicados basándose en el valor de uno o más campos clave. Puede mantener el primer o el último duplicado. También puede comparar con ejecuciones anteriores para detectar items nuevos.

DedupUniqueDISTINCT
✂️
Limit
Data

Limita el número de items que pasan al siguiente nodo. Se puede mantener los primeros N o los últimos N items. Útil para pruebas, paginación manual o limitar procesamiento costoso.

LímitePaginaciónLIMIT
📊
Summarize
Data

Agrupa items por un campo y calcula estadísticas para cada grupo: suma, promedio, mínimo, máximo, conteo, valores únicos. Similar a un GROUP BY con funciones de agregación en SQL.

GROUP BYEstadísticasSumaMedia
🔄
XML / JSON / CSV Convert
Data

Convierte datos entre formatos: XML↔JSON, CSV↔JSON. Permite parsear strings XML a objetos JavaScript, serializar JSON a XML o procesar archivos CSV línea a línea. Fundamental para integraciones con sistemas legacy.

XMLJSONCSVParse
🔐
Crypto
Data

Aplica funciones criptográficas a datos: hashing (MD5, SHA1, SHA256, SHA512), HMAC, y generación de firmas. Útil para verificar integridad de webhooks, generar tokens o firmar solicitudes.

HashSHA256HMACFirma
🤖
AI Agent
AI

Crea un agente AI autónomo con acceso a herramientas (tools). El agente decide qué herramientas usar, las ejecuta en ciclos iterativos y produce una respuesta final. Soporta ReAct, OpenAI Functions y más.

LLMAgenteToolsReActAutónomo
💬
Basic LLM Chain
AI

Envía un prompt a un LLM (OpenAI, Anthropic, Google, etc.) y devuelve la respuesta. La cadena más simple: prompt → modelo → texto. Configurable con system prompt, temperatura y modelo.

LLMPromptChatCompletions
🧠
OpenAI
AI

Integración nativa con la API de OpenAI. Soporta chat completions (GPT-4, GPT-4o), generación de imágenes (DALL-E), embeddings, moderación, análisis de audio (Whisper) y TTS desde un solo nodo.

GPT-4DALL-EEmbeddingsWhisper
🗄️
Vector Store
AI

Inserta o consulta documentos en una base de datos vectorial (Pinecone, Qdrant, Supabase, PGVector, Weaviate, etc.). Fundamental para sistemas RAG (Retrieval Augmented Generation) y búsqueda semántica.

RAGEmbeddingsSemánticaPinecone
🧩
Memory (Buffer / Window)
AI

Almacena y recupera el historial de conversación para agentes o chains. Tipos: Buffer Memory (historial completo), Window Memory (últimos N mensajes), Summary Memory (resumen comprimido).

MemoriaHistoriaConversaciónContext
📄
Document Loader / Text Splitter
AI

Carga documentos (PDF, HTML, JSON, CSV, texto plano) y los divide en chunks para ingesta en vector stores. El Text Splitter controla tamaño y overlap de fragmentos. Primer paso de pipelines RAG.

PDFChunkingRAGIngesta
💡
Information Extractor
AI

Usa un LLM para extraer información estructurada de texto libre. Define un schema de salida (campos y tipos) y el modelo completa los valores a partir del texto de entrada. Ideal para parsear emails, reviews o documentos.

ExtracciónStructured OutputSchema
📩
Gmail
Integración

Lee, envía, mueve y elimina emails de Gmail. Busca mensajes con filtros, obtiene adjuntos, marca como leído, añade etiquetas. También tiene trigger para nuevos emails sin necesidad de IMAP.

EmailGoogleSMTPAdjuntos
📗
Google Sheets
Integración

Lee, escribe, actualiza y elimina filas en Google Sheets. Soporta append (agregar al final), update por coincidencia de clave, lectura de rangos y creación de hojas. El "mini-database" más popular en n8n.

SpreadsheetGoogleDatabaseCRUD
💬
Slack
Integración

Envía mensajes, crea canales, obtiene usuarios, reacciona a mensajes y gestiona archivos en Slack. Soporta Block Kit para mensajes enriquecidos. Trigger disponible para eventos de workspace.

MensajesNotificaciónBlock Kit
🗃️
Postgres / MySQL / SQL
Integración

Ejecuta consultas SQL en bases de datos relacionales. Soporta SELECT, INSERT, UPDATE, DELETE y queries personalizadas. Mapea automáticamente resultados a items de n8n. También disponible: SQLite, MS SQL, MariaDB.

SQLDatabasePostgreSQLMySQL
🗂️
Airtable
Integración

Lee, crea, actualiza y elimina registros en bases de Airtable. Soporta búsquedas con fórmulas, campos de archivo y relaciones entre tablas. Trigger para cambios en registros. Popular como CRM ligero.

NoCode DBCRMCRUD
📒
Notion
Integración

Crea, lee, actualiza y busca páginas y entradas de bases de datos en Notion. Soporta todos los tipos de bloques (texto, listas, tablas) y propiedades de bases de datos (fecha, select, relación, etc.).

PagesDatabasePKM
✈️
Telegram
Integración

Envía mensajes, fotos, documentos y stickers vía Telegram Bot API. Trigger para recibir mensajes o comandos. Soporta inline keyboards, grupos y canales. Ideal para bots de notificación o chatbots.

BotMensajesNotificación
🐙
GitHub
Integración

Interactúa con repositorios de GitHub: crea/actualiza issues, pull requests, comentarios, releases y archivos. Trigger para eventos de repo (push, PR abierto, issue creado). Ideal para pipelines de DevOps.

IssuesPRDevOpsCI/CD
💳
Stripe
Integración

Gestiona clientes, cargos, suscripciones, facturas y reembolsos en Stripe. Trigger vía webhooks de Stripe para eventos de pago. Permite automatizar flujos post-compra, notificaciones y actualizaciones de estado.

PagosSuscripcionesE-commerce
🏢
HubSpot
Integración

Crea y actualiza contactos, empresas, deals y tickets en HubSpot CRM. Gestiona propiedades personalizadas, listas, flujos de trabajo y emails. Ideal para sincronizar leads entre sistemas de marketing y ventas.

CRMLeadsMarketingSales
📁
Google Drive
Integración

Sube, descarga, mueve, copia y elimina archivos en Google Drive. Crea carpetas, lista archivos con filtros y comparte con permisos específicos. Trigger para cambios en carpetas o archivos.

ArchivosCloudGoogle
📱
WhatsApp Business
Integración

Envía mensajes de texto, plantillas aprobadas, imágenes, documentos y mensajes interactivos vía la API oficial de WhatsApp Business. Trigger para mensajes entrantes. Requiere cuenta WhatsApp Business API.

WhatsAppMensajesPlantillas
📅
Date & Time
Utilidades

Formatea, convierte y calcula fechas y horas. Cambia zonas horarias, suma/resta intervalos (días, horas, minutos), calcula diferencias entre fechas y extrae componentes (mes, año, día de la semana).

FechasTimezoneFormateo
📮
Send Email (SMTP)
Utilidades

Envía emails vía cualquier servidor SMTP configurado. Soporta HTML o texto plano, múltiples destinatarios (To/CC/BCC), adjuntos y headers personalizados. Alternativa genérica a Gmail cuando no se usa Google.

SMTPEmailHTMLAdjuntos
💾
Read/Write Files
Utilidades

Lee y escribe archivos binarios o de texto en el sistema de archivos donde corre n8n. Útil en instancias self-hosted para leer CSVs locales, guardar PDFs procesados o manejar adjuntos temporales.

ArchivosBinarioLocal
🗜️
Compression
Utilidades

Comprime archivos en formato ZIP o GZIP, y descomprime archivos ZIP recibidos. Permite empaquetar múltiples archivos en un solo ZIP para enviarlos por email o almacenarlos en la nube.

ZIPGZIPComprimir
🕸️
HTML Extract
Utilidades

Extrae datos de HTML usando selectores CSS. Ideal para web scraping básico sobre HTML ya descargado (desde HTTP Request). Obtiene texto, atributos (href, src) o HTML interno de elementos.

ScrapingCSSParse HTML
📝
Markdown
Utilidades

Convierte Markdown a HTML y viceversa. Útil para preparar contenido generado por LLMs (que suelen devolver Markdown) para enviarlo como email HTML o almacenarlo como texto limpio.

MarkdownHTMLConversión
🔔
No-Op (No Operation)
Utilidades

No hace nada. Pasa los datos tal cual al siguiente nodo. Útil como marcador de posición durante desarrollo, para documentar bifurcaciones vacías o como punto de conexión temporal en un flujo.
